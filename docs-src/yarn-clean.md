## Yarn Cache Cleaner (Python)

Python-based utility to clean Yarn caches.

### Usage

```bash
yarn-clean
```

### Description

Runs `yarn-clean.py` which locates and cleans Yarn cache directories. Available as a shell wrapper in both bash and batch variants.
